== Was ist neu in der neuesten Version von NetApp ONTAP für AFX?

Neueste Version:

ONTAP 9.19.1RC1 (Stand: Mai 2026)

Neue Funktionen in NetApp AFX:

* Globale Deduplizierung
* Dynamische Speichereffizienz
* Erweiterte Lesevorschau
* Unterstützung für 32 Knoten
* 32PB-Unterstützung
* 512 Bestandteilvolumina pro FlexGroup volume
